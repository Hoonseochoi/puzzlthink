# 04. 데이터 보안(Data safety) 양식 답안

Play Console → 앱 콘텐츠 → **데이터 보안**. 앱은 www.puzzlthink.com을 여는 Trusted Web Activity라서, 사이트가 처리하는 데이터가 곧 앱의 데이터예요. 2026-11-27 코드 기준으로 정리했어요.

근거가 된 코드: Google 로그인·프로필(`src/components/AuthProvider.tsx`, `touch_profile`), 게임 기록(`game_results` 등), 이용 시간(`track_activity`), 라운지(`src/lib/lounge.ts`), 오류 제보(`src/components/BugReport.tsx`, Web3Forms로 메일 전달), Google Analytics 4(`src/lib/analytics.ts`), 방문 수·접속자 수(`record_visit`, `online_ping` — 익명 집계). 앱에서는 AdSense와 히든로그 배너가 꺼져 있어 광고 데이터는 없어요. APK의 Android 권한은 앱 자체 내부 권한 하나뿐이고 광고 ID 권한이 없어요.

## 첫 화면 질문

| 질문 | 답 |
|---|---|
| 필수 사용자 데이터 유형을 수집하거나 공유하나요? | **예** |
| 수집되는 모든 사용자 데이터가 전송 중 암호화되나요? | **예** (HTTPS만 사용) |
| 사용자가 데이터 삭제를 요청할 수 있는 방법을 제공하나요? | **예** — 앱 안 계정 메뉴 → 회원탈퇴, 웹 `https://www.puzzlthink.com/ko/account-deletion` |
| 계정 만들기 | 예 — "OAuth(Google 로그인)" 선택. 로그인 없이도 이용 가능 |
| 계정 삭제 URL | `https://www.puzzlthink.com/ko/account-deletion` |
| 독립 보안 검토 | 아니요 |

## 데이터 유형별 답

"공유"는 제3자에게 넘기는 것이에요. Supabase(자체 호스팅), Google Analytics, Web3Forms처럼 **우리를 대신해 처리하는 서비스 제공업체**로 보내는 건 Play 기준상 공유가 아니에요.

| 카테고리 → 유형 | 수집 | 공유 | 처리 방식 | 필수/선택 | 목적 |
|---|---|---|---|---|---|
| 개인 정보 → **이름** | 예 | 아니요 | 임시 아님 | 선택(로그인할 때) | 계정 관리 |
| 개인 정보 → **이메일 주소** | 예 | 아니요 | 임시 아님 | 선택(로그인할 때, 오류 제보 시 답장 주소) | 계정 관리, 개발자 커뮤니케이션 |
| 개인 정보 → **사용자 ID** | 예 | 아니요 | 임시 아님 | 선택 | 계정 관리, 앱 기능 |
| 개인 정보 → 기타 정보 | 예 (닉네임, Google 프로필 사진 주소) | 아니요 | | 선택 | 앱 기능, 계정 관리 |
| 메시지 → **기타 인앱 메시지** | 예 (라운지 채팅, 방 이모트) | 아니요 | | 선택 | 앱 기능 (다른 사용자에게 공개), 사기 방지·보안(신고 처리) |
| 앱 활동 → **앱 상호작용** | 예 (게임 기록, 이용 시간, 방문 통계) | 아니요 | | 필수 아님(로그인 시 저장) / 통계는 자동 | 앱 기능, 분석 |
| 앱 활동 → **기타 사용자 생성 콘텐츠** | 예 (닉네임, 방 제목, 오류 제보 내용) | 아니요 | | 선택 | 앱 기능, 개발자 커뮤니케이션 |
| 앱 정보 및 성능 → 진단 | 예 (오류 제보에 함께 보내는 브라우저 정보·화면 크기) | 아니요 | | 선택 | 분석(버그 수정) |
| 기기 또는 기타 ID | 예 (Google Analytics 쿠키 ID) | 아니요 | | 필수(통계) | 분석 |
| 위치 → **대략적인 위치** | 예 (Google Analytics가 IP로 추정하는 지역; IP 자체는 저장 안 함) | 아니요 | | 필수(통계) | 분석 |

수집하지 않음: 정확한 위치, 금융 정보, 건강, 사진·동영상, 오디오, 파일, 캘린더, 연락처, 웹 기록, 설치된 앱, 광고 ID.

> 판단이 갈리는 곳: GA의 "대략적인 위치"는 적지 않는 앱도 많지만, 적어서 문제가 되는 일은 없고 빠뜨리면 지적받을 수 있어 넣었어요. 나중에 Google Analytics를 앱에서 끄면(지금은 웹과 똑같이 켜져 있음) "기기 ID·대략적 위치·분석 목적"을 빼면 돼요.

## 보관과 삭제 (방침과 같은 내용)
- 계정·기록·라운지 메시지: 회원탈퇴 즉시 삭제(공유 기록은 이름만 지움 — [06](06-privacy-and-account-deletion.md)).
- 오류 제보: 메일 주소와 계정 연결을 지운 채 내용만 보관.
