# 05. 타깃층·가족 정책·광고

## 타깃 연령층 (앱 콘텐츠 → 타깃층 및 콘텐츠)

**선택: 13–15세, 16–17세, 18세 이상.** 13세 미만(5세 이하, 6–8, 9–12)은 체크하지 않아요.

| 선택 | 결과 |
|---|---|
| 13세 이상만 (권장) | 가족 정책(Families) 대상이 아니에요. 사용자 간 채팅(라운지)이 있어도 아동용 요건(나이 확인 화면, 보호자 관리, 승인된 광고 SDK만, 개인 식별자 전송 금지)이 붙지 않아요. 개인정보처리방침의 "만 14세 미만 아동의 개인정보를 의도적으로 수집하지 않음"과도 맞아요. |
| 13세 미만 포함 | 가족 정책 전체가 적용돼요: 아동 대상 콘텐츠 기준, COPPA·GDPR 준수, Google Analytics 같은 식별자 전송 제한, 라운지 같은 소셜 기능에 보호자 관리·안전 알림, 중립적인 연령 확인. 지금 사이트 구조로는 맞추기 어려워 **선택하지 마세요.** |

- "아동에게 의도치 않게 어필하나요?" 같은 질문이 나오면 **아니요**: 캐릭터 말이 귀엽긴 하지만 게임은 전략·추리·논리 퍼즐이고, 설명과 그림도 아동을 겨냥하지 않아요. 심사에서 "아동 어필"로 판단하면 가족 정책 요건을 요구할 수 있다는 점만 알아두세요.
- 스토어 등록정보에서 "어린이용" "키즈" 같은 말은 쓰지 마세요.

## 광고

**선언: "아니요, 앱에 광고가 없습니다."**

근거(앱 모드, `src/lib/playApp.ts`의 `PLAY_APP_HIDE`):
- `ads: true` — AdSense 스크립트를 아예 불러오지 않고 광고 칸과 그 자리도 없음. 2026-11-27 로컬 Workers 빌드에서 앱 모드 27개 화면을 열어 광고 도메인(googlesyndication·doubleclick·adservice·googleads·adtrafficquality) 요청 **0건**을 확인했어요(웹 모드는 같은 화면에서 11–13건).
- `hiddenlog: true` — 직접 판매 배너(히든로그) 상단 띠·결과 카드도 숨기고, 노출·클릭을 세지 않음.
- `support: true` — 후원 배너·카드(광고 자리를 대신하던 것)도 숨김.

나중에 앱에서 광고를 켜면: 광고 선언을 "예"로 바꾸고, 콘텐츠 등급 설문에서도 광고 여부를 갱신하세요(광고 내용이 앱 등급보다 성인적이면 안 됨). 13세 이상 타깃이면 가족 정책 광고 요건은 없어요.

## 광고 ID
"광고 ID를 사용하나요?" → **아니요**. 앱(TWA)에 광고 SDK가 없고, APK에 `com.google.android.gms.permission.AD_ID` 권한이 없어요.

## 결제·후원 (정책 확인 결과)
- Play 결제 정책: 앱 안에서 디지털 상품·혜택을 팔면 Google Play 결제를 써야 하고, 앱 안에서 다른 결제 수단으로 안내하는 링크·버튼은 금지(대체 결제·외부 링크 프로그램에 등록한 경우 제외). 세금 공제 가능한 순수 기부만 예외예요.
- PUZZLTHINK 후원(CTEE, ₩3,000)은 **후원자 커버(앱 안에서 쓰는 혜택)**를 주므로 순수 기부로 보기 어려워요 → 앱 모드에서 후원 버튼·배너·결과 카드·"후원자 커버 받기" 카드를 **모두 숨겼어요**(`support: true`). 이미 커버를 가진 사람의 켜기/끄기는 다른 곳에서 산 것을 쓰는 것이라 남겼어요.
- 한국의 "사용자 선택 결제(대체 결제)"를 쓰면 앱 안 후원도 가능하지만 결제 API 연동이 필요해 이번 범위가 아니에요.
