# 03. 콘텐츠 등급(IARC) 설문 답안지

Play Console → 정책 및 프로그램 → 앱 콘텐츠 → **콘텐츠 등급** → 설문 시작.
- 이메일: `contact@puzzlthink.com` · 카테고리: **게임(Game)** (참고용·소셜·엔터테인먼트가 아님)
- 앱은 사이트를 그대로 여는 앱이라 **앱 모드에서 보이는 내용**이 답의 기준이에요. 광고는 앱에 없어요.

> 설문 문구: Google/IARC 설문은 공개된 원문이 없어 이 문서는 **질문의 취지**를 적었어요. 콘솔 화면의 문구를 읽고, 아래 사실관계에 맞는 쪽을 고르세요. 사실과 다르게 답하면 정책 위반(앱 삭제·계정 정지 사유)이 되니, 애매하면 "예"가 안전해요.
> 도박 항목은 대체로 세 갈래로 물어요: ① **실제 돈을 걸거나 따는 도박**(real-money gambling)이 있는가, ② **도박을 흉내 낸 게임 플레이(시뮬레이션 도박, simulated gambling)** — 카드·카지노식 게임에서 실제 가치 없는 칩·점수로 베팅하는 것 — 이 있는가, ③ 도박을 **권장·미화**하거나 도박에 대한 언급·주제가 있는가. 콘솔이 "Does the app contain simulated gambling?" 같은 질문을 띄우면 아래 변형 A에서는 **예**예요.

## 실제로 제출한 답 (2026-11-27)

운영자 결정으로 도박 질문("게임에 도박, 카지노 도박/빙고 모사, 도박 테마가 있습니까?")은 **아니요**로 제출했어요. 폭력도 아니요, 사용자 소통은 예(차단·신고·채팅 조정 예, 친구로만 제한 아니요). 결과: 한국(GRAC)·ESRB 등 전 지역 **전체이용가**. 아래 변형 A의 "시뮬레이션 도박: 예"와 다르니, 심사에서 등급 재설문 요청이 오면 변형 A(예) 또는 변형 B(게임 숨김)로 다시 제출하세요.

## 앱 안에 있는 것 (사실관계)

| 항목 | 내용 |
|---|---|
| 베팅이 있는 게임 | **인디언 포커**(카드 1장, 칩 베팅·콜·폴드), **양면포커**(카드·칩 베팅), **Hit,Stay**(카드를 받으며 칩을 거는 블랙잭식), **스나이퍼 홀덤**(홀덤식 족보, 칩 베팅, 점점 오르는 앤티) — 모두 **실제 가치 없는 게임 칩**, 사거나 팔거나 돈·상품으로 바꿀 수 없음 |
| 베팅으로 볼 여지가 있는 다른 게임 | **시간 경매**(남은 *시간*으로 바둑알에 입찰하는 경매) · **흑과 백 / 흑과 백 II**(숫자 타일 대결, 걸기 없음) · **돼지 저금통**(동전 *개수*를 맞히는 추리, 걸기 없음) · **무거운 13**(색 칩은 카드를 놓는 토큰, 걸기 없음) · **러시안 룰렛**(확률 게임, 걸기 없음). 이 다섯은 **돈이나 칩을 거는 도박 흉내가 아니라고 판단**했어요. 시간 경매는 입찰 메커니즘이 있어 "경매/입찰"이 질문에 따로 나오면 예로 답하세요. |
| 무기·폭력 | **러시안 룰렛**: 그림체의 리볼버, "실탄 격발/빈 약실", "가상 피탄 표적". 사람·캐릭터가 다치거나 피·죽음이 그려지지 않음(탈락만 표시). 그 밖의 게임에 폭력 없음 |
| 공포·성적 내용·욕설·약물·음주·흡연·차별 | 없음 (라운지·닉네임 욕설은 자동 필터로 막음) |
| 사용자 간 소통 | **예** — 라운지(공개 채팅), 닉네임 공개, 친구/오픈 대전 방(방 안 이모트·채팅). 신고·차단·자동 필터·운영자 조치 있음 |
| 위치 공유 | 아니요 |
| 디지털 상품 구매 | 아니요 (인앱 결제 없음, 앱에서 후원 링크 숨김) |
| 무제한 인터넷 접근(브라우저처럼 아무 사이트나) | 아니요 — 앱은 puzzlthink.com만 열고, 바깥 링크는 별도 브라우저 탭으로 |
| 사용자 생성 콘텐츠 공유 | 라운지 메시지·닉네임·방 제목 (텍스트만, 이미지·영상 없음) |
| 광고 | 없음 |

**예상 등급** (확정 아님, 설문 결과가 정답이에요)
- 국제(IARC 일반): 12+ 안팎 — 시뮬레이션 도박이 보통 12+로 분류돼요.
- 유럽 PEGI: 12 또는 그 이상 (도박을 흉내 낸 게임에 대한 PEGI 기준은 최근 강화된 적이 있어 18이 나올 수도 있어요).
- 미국 ESRB: T(Teen)일 가능성.
- **한국(게임물관리위원회 기준)**: 카드·카지노 도박을 흉내 낸 게임은 **청소년이용불가**가 나올 수 있어요(포커 족보를 쓰는 Balatro 사례). 비슷한 앱(인디언포커·양면포커·"베팅! 흑과백"이 있는 데스매치온라인)은 전체이용가로 올라 있지만, 그건 그 앱이 낸 답의 결과라 우리 결과를 보장하지 않아요.
- "사용자 소통 있음" 표시가 붙어요(등급을 올리진 않음).

## 변형 B — 베팅 게임 숨김 (예비)

`src/lib/playApp.ts`의 `PLAY_APP_HIDDEN_GAMES`에 아래 네 줄을 넣고 배포하면, 앱 안 어디에도 그 게임이 보이지 않고 주소로 열어도 "웹에서 이용할 수 있어요" 화면이 나와요(사이트는 그대로).

```ts
export const PLAY_APP_HIDDEN_GAMES: readonly string[] = [
  'indianPoker',
  'twoSidedPoker',
  'hitStay',
  'sniperHoldem',
];
```

그 뒤 설문을 **다시 제출**:

| 질문 취지 | 답 |
|---|---|
| 실제 돈 도박 | 아니요 |
| 시뮬레이션 도박 | **아니요** |
| 도박 언급 | 아니요 (러시안 룰렛·시간 경매는 걸기가 없음; 앱에는 게임 이론·백과 같은 글 섹션도 없음) |
| 무기 묘사 | 예 — 경미 (러시안 룰렛). 러시안 룰렛까지 숨기면 `'russianRoulette'`를 추가하고 아니요 |
| 나머지 | 변형 A와 같음 |

예상: 국제 3+~7+ / PEGI 3~7 / 한국 전체이용가~12세 (러시안 룰렛을 남기면 무기 표현 때문에 한 단계 높을 수 있음).

## 결과가 청소년이용불가(19)로 나오면

1. 그대로 두면 한국에서 만 19세 미만은 설치할 수 없고, 앱 소개에 19 표시가 붙어요. 사이트 이용자층(10대 포함)을 생각하면 권하지 않아요.
2. **변형 B로 바꿔 다시 받기**: 위 네 줄 추가 → 사이트 배포(앱 재업로드 필요 없음) → 콘텐츠 등급 → 설문 다시 시작 → 변형 B 답 → 제출. 새 등급은 보통 바로 반영돼요.
3. 결과가 납득되지 않으면 IARC 등급 확인 메일의 "이의 제기(Appeal)" 링크로 재검토를 요청할 수 있어요(한국은 게임물관리위원회 기준).
4. 답을 사실과 다르게 바꾸는 방식(베팅 게임을 그대로 두고 "아니요")은 쓰지 마세요.

## 나중에 다시 제출해야 하는 경우
- 숨김 목록을 바꿨을 때(게임이 앱에 새로 보이거나 사라짐)
- 앱에 보이는 새 게임이 베팅·칩, 무기·폭력, 실제 보상, 결제를 가졌을 때 (새 게임이 들어올 때마다 위 "사실관계" 표를 한 줄 갱신하세요)
- 광고를 다시 켤 때(광고 선언도 함께)
