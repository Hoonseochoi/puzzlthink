## 확인한 것

2026-11-27, 이 브랜치의 `npm run build:vinext`(Cloudflare Workers 런타임, `vite preview`) 하나로:
- **앱 모드 vs 웹** — Playwright(headless Chrome, 412×915 휴대전화)로 27개 주소(홈 ko/en, 게임 목록, 게임 소개, 기록실, 아이콘, 헬모드, 벽바둑, 인디언 포커, 스나이퍼 홀덤, 시간 경매, 히든 워드 확장판, 슬리더링크, 회원탈퇴, 약관, 방침, 공략 허브·개별 공략 2개, 개발 노트 허브·글, 보드게임 백과 허브·글, 서바이벌 게임 정리 허브·게임, 게임 이론 허브·글)를 두 모드로 열어 비교:
  - 앱: 광고 도메인 요청 **0**, AdSense 스크립트 없음, 광고 칸 0, 히든로그 링크 0, 후원 링크 0, 글 섹션 링크 0, 글 섹션 10개 주소는 모두 중립 화면, 베팅 게임은 보임.
  - 웹: 같은 주소에서 광고 요청 11–13건, AdSense 스크립트 있음, 히든로그 배너(캠페인 12/2까지), 후원 링크, 글 링크, 글 페이지 정상.
- 프록시의 중립 화면 응답은 `no-store`(캐시 안 됨), 앱 요청 뒤에도 웹 요청은 원래 페이지(첫 작업 때 확인).
- `/.well-known/assetlinks.json` → `application/json`, 업로드 키 지문.
- 회원탈퇴·닉네임 필터 마이그레이션: 스크래치 DB에서 17/17, 4/4.
- `npx tsc --noEmit`, 바꾼 파일 eslint 통과.

## 확인하지 못한 것
- **실기기/에뮬레이터 실행**: 이번엔 하지 않았어요(디스크·메모리 사정). 첫 작업 때 Android 16 에뮬레이터에 APK를 설치해 스플래시(색·아이콘)까지는 확인했지만, 운영 사이트에 assetlinks가 없어 전체 화면 여부는 볼 수 없었어요. → 내부 테스트로 설치해서 확인 (체크리스트 5단계).
- **TWA 안 Google 로그인**: 사이트 로그인은 Google 하나뿐(Supabase OAuth 리디렉션 + Google Identity Services 버튼). TWA는 진짜 Chrome이라 Google이 막는 "웹뷰 로그인"에 해당하지 않아 동작할 것으로 보지만, 실제 앱에서 확인하지 못했어요. 히든 워드 확장판(회원 전용)도 같은 로그인이에요.
- 라이브 DB의 gotrue 추가 표가 탈퇴 때 같이 지워지는지(설계상 CASCADE).
- 콘텐츠 등급 실제 결과(설문 결과가 정답).
